# `libtechmino-vlq`

A helper crate used by `libtechmino-replay` for VLQ data processing.

- `#![no_std]` support (`--no-default-features`)
  - However, we require `alloc`

# Minimum Supported Rust Version
**Current MSRV: `1.84.1`**

MSRV bumps are out of scope of semver changes. This means it may be changed across minor or patch updates.
